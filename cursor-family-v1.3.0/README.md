# v1.3.0 双线尺寸修复源码

原版就是非避让版，保留原有完整像素、尺寸、构图和动画；新避让版保留已确认的候选比例并避让真实提示框/输入法。两线都使用默认 32×32 的共享系统光标和独立显示层，提供普通/Plus及各档位。

本目录保留两套运行时 C#、控制脚本、角色目录和包内校验。完整可编辑 PNG、ANI 及所需资源包含在同发行的相应安装 ZIP 中。要重编译，请先解压安装 ZIP，再在其目录运行 `rebuild.ps1`；源码目录单独检出时尚无全部运行资源。

跨仓库换用同一产品线时保留最初的 Windows 恢复记录。旧根目录、旧源码及旧发行保留；日常使用请下载 v1.3.0 对应产品线的安装包。

验收记录与已知限制见同发行的 validation-report.json；展示视频来自真实虚拟机录屏。虚拟机工程检查不代表用户的 200 Hz 手感或具体游戏验收。

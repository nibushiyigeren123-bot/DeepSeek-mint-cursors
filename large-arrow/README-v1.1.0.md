# DeepSeek 小鲸鱼 放大指针版

与原版同仓库、独立方案和安装目录。完整解压后双击应用CMD，默认推荐画布72px档；需要持续保持尺寸与颜色，再运行“尺寸保持_开启.cmd”。普通应用保留保持器原先的开启/停止状态。

提供32/48/64/72/128/256px六档组合画布，72px中的人物保留原版48px人物图层像素；其他档从原始动作源按同一冻结布局比例生成。放大的是功能符号，人物位于右下，全部相位不重叠。各角色按其轮廓固定位置，尺寸切换不重新摆位。动画来源与程序动作方式沿原版，不代表新增手绘动作帧。

“切回_角色_原版”入口附带本次更新原版资源；“恢复安装前指针”只返回上一套方案。原版保持原名字，本版使用LargeArrow方案名，支持来回切换。

本次同步修正小尺寸人物发浅的加载问题，原始角色美术保留。系统设置/INF直接选择仍走系统文件加载；开启本版尺寸保持后按修正方式重载。程序许可、角色出处沿上一级原版README及源码资料，source内保留原图与可重建生成器。

首次应用不会自行启动尺寸保持。可用“尺寸保持_开启.cmd”主动开启，“关闭/卸载”入口可停止并移除登录启动项。人物来源与原版完整说明随包见source/ORIGINAL-README.md和美术许可文件。

# v1.4.0 实现与验证边界

Windows ANI 承载完整的 17 种功能光标；人物用独立、点击穿透的分层窗口绘制。v1.3.2 的原生尺寸、热点、帧资源与高 DPI 固定间距算法作为本版基线，人物透明度不改变任何系统光标或点击坐标。

`Program.Controller` 每 500 毫秒核对选定方案、17 路径与逻辑尺寸，负责装载当前 profile、原生光标提交和状态文件。`AvatarHost` 的独立 STA 读取缓存并跟踪位置；`IdleFade` 只根据停留锚点、时间和拖动状态输出人物透明度。微动围绕停留锚点累计，超过默认 3 个逻辑像素才恢复，阈值按实际 DPI 比例换算。完全透明时停止人物帧上传。

`PopupCache` 使用窗口创建/显示/隐藏/位置/名称事件及有界缓存。原生 tooltip/候选窗走 HWND 矩形；TextInputHost 和符合小工具弹窗条件的窗口才做有限 UI Automation 查询。最多一个语义查询、每窗至少 250 毫秒间隔；渲染线程不执行截图、窗口遍历或 UIA。无独立 HWND/可用语义的自绘提示由停留淡出处理。

`control.ps1` 在停止和写方案前保存原系统设置、17 个源路径与实际共享几何，以及先前有效 profile、Run 和同会话运行意图。停止直接通知已核实路径/会话实例的已知事件，未运行时不执行 EXE。失败回退各阶段独立，停止异常不阻断安全恢复；每次写系统方案前复核所有权。

登录项为 `AICursorFamilyFullAvoidance`，入口是本版 EXE。保留原 30 秒启动恢复宽限和会话结束逻辑；运行状态同时报告 PID、启动时间、会话、完整路径与帧计数。重启验收必须取得真实新 boot、自动创建的新进程和移动/停留后的画面，不能用状态文件或手动 Enable 代替。

旧 v1.3.1 记录没有原始共享位图观测，不会补造历史：只恢复其记录字段及系统方案；缺失 CursorBaseSize 时仅按该旧版从未改动它的明确合同保留迁移前现值。旧 v1.3.2 schema2 缺失原始尺寸/原生基线则拒绝猜测。全部源资产可编辑，但原 PNG/ANI 仍需保持帧数、尺寸、热点与资源预算。

旧版说明与发布契约作为历史来源由维护者保留。当前发布摘要在 `candidate-consistency.json` 与 `release-equivalence.json`；公开技术验证范围见 `VALIDATION.md`。

启用先核验全包哈希，再核对现有实例的精确路径和进程完整性，之后才迁移/写方案。若人物此前由管理员启动，普通入口明确拒绝并保留原实例、方案和Run；须用同样权限关闭它后再普通启用，不自动提升权限。目录解析兼容Windows PowerShell5.1与PowerShell7，先赋值再逐profile枚举，拒绝未知目录结构；不在产品内泛化修复损坏JSON。

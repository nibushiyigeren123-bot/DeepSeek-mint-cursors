# v1.3.1 验证范围与已知限制

本版共同修复：高屏幕缩放下 Person 共享光标尺寸检查失败；登录/重启后人物恢复；人物被降为普通窗口后的置顶恢复。角色 PNG、ANI、动画节奏及尺寸选项保持原样。

Windows 10 Build 19045 与 Windows 11 Build 26300 虚拟机均覆盖两产品线的 100%、125%、150%、200% 缩放、17 系统光标状态。完成 6 组正常重启观察、两次主动降层后恢复、短暂/持续方案失配、显式停止与默认 Person 像素/热点恢复。以 Astra 验证共用引擎，并抽查 Gemini 普通/Plus、8 帧资源与跨包切换；没有重跑全 416 配置运行矩阵。全部 22 包通过成员、哈希与帧引用校验，50048 份素材成员保持原字节。

48 个可见性能样本使用 4 vCPU / 8 GiB VM、96/256 尺寸，每次约 6 秒，包含静止与移动。工作集约 28–62 MiB，移动 CPU 最高约占 VM 总量 0.456%；Win10 同条件对照未显示明显开销增长。这是短时参考，并非上限，实际受设备、尺寸、刷新率和场景影响；GPU/显存未独立测量。

保留的边界：

- Windows 11 登录后自然启动曾延迟约 46 秒；启动恢复不等于登录瞬间出现，请稍等。
- 有多主题安装记录时，关闭后 Person 注册表路径可能已恢复，但共享像素与自定义主题不一致。该 Stop 路径本轮未改，未证实相对旧版的因果；系统默认 Person 回退在两系统两线均通过。若遇到此边界，可在 Windows 鼠标属性重新选择并应用希望使用的方案。
- Win11 旧版基线曾被 Defender 隔离，因此部分旧版性能对照缺失。候选约 23 分钟观察内没有新增检测，防护设置未改；不代表未来安全签名或全部设备均已验证。
- 尚未在 Surface Pro 7 的 2736×1824 实机、多屏混合 DPI、200 Hz 或高于 200% 缩放环境验收。VM 桌面捕获为 1024×768，跟随状态约 64 Hz。
- ANI 结构及原始帧字节保留；源图案相同的 step 不用于声称已观察到不同动画图案。

运行核心 SHA256 与完整结构化范围见同目录 validation-report.json。公开资料对应本次受测核心；发行包与 RC2 仅 README、方案版本文字不同，最终两线 v1.3.1 包完成 Win11 实际启用/显示/停止烟测。

# DeepSeek 小鲸鱼 原版 · v1.2.0

人物和功能符号使用同一套角色配色，保留原有动态动作。Plus与同档原版人物一样大，仅功能符号更醒目。

## 安装与切换

1. 从本仓库最新Release下载安装包并完整解压。
2. 双击对应角色、对应尺寸的 `应用_角色_尺寸px.cmd`。命令会应用该尺寸并更新、启用本包尺寸保持器。
3. 之后换尺寸，直接运行另一档CMD；切到Windows默认或其他方案时，本包保持器自动停止接管。

右键INF安装只复制文件、登记方案；再运行 `尺寸保持_开启.cmd`，并在鼠标属性中选择对应方案，才能按本包像素和颜色显示。

`尺寸保持_关闭.cmd` / `尺寸保持_卸载.cmd` 仅处理本包保持器及登录启动，光标文件和方案保留。`恢复安装前指针.cmd` 恢复保存的上一方案。

若旧版曾改变Windows全局大小，先在Windows设置的指针大小滑块恢复惯用档位一次；新版不猜测和覆盖原数值。

## 尺寸与人物大小

| 档位 | 人物基准画布 | 本版实际透明画布 |
| --- | --- | --- |
| 32px | 32×32 | 32×32 |
| 48px | 48×48 | 48×48 |
| 64px | 64×64 | 64×64 |
| 96px | 96×96 | 96×96 |
| 128px | 128×128 | 128×128 |
| 256px | 256×256 | 256×256 |

档位用于匹配原版人物大小；人物自身的可见宽高因动作而异。Plus增加的是透明留白，保持器按实际画布加载，所以人物不会随透明画布缩小。Windows鼠标属性的小预览会自行缩放，实际大小以应用后为准。

Plus72px为新增人物基准档，原版安装档位没有72px；它从同一原始动作源按72px基准生成。
